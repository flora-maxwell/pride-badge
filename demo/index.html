pride-badge

A small pride badge for your website. Click it: pride flags fly and the next sentence rolls in. Move your mouse close for a rainbow trail.

Add it to your site

Two lines, from the CDN:

<script src="https://cdn.jsdelivr.net/npm/pride-badge@1/dist/pride-badge.js" defer></script>

<pride-badge></pride-badge>

Or host the file yourself (no third party sees your visitors), or npm install pride-badge. All the details are in the README.

Pick your sentences

texts sets which sentences take turns, in this order. One sentence means no change, only flags.

<pride-badge texts="safe-with-me love-is-love"></pride-badge>
<pride-badge texts="you-belong"></pride-badge>

Auf Deutsch

lang="de", or nothing at all if your page is already German.

<pride-badge lang="de"></pride-badge>

Dark

Colours, contour and shadow come from CSS custom properties.

pride-badge {
  --pride-badge-bg: #27272a;
  --pride-badge-color: #fafafa;
  --pride-badge-contour: 0 0 0 1px rgb(255 255 255 / .16);
  --pride-badge-shadow: 0 1px 2px rgb(0 0 0 / .3), 0 4px 14px rgb(0 0 0 / .35);
}

Quieter

shadow="off" drops the shadow, trail="off" leaves no rainbow trail behind the mouse or a finger, touch-trail="off" keeps it for the mouse only and lets the page scroll when a finger starts on the badge, effects="off" makes it a calm button.

shadow="off"
trail="off"
touch-trail="off"
effects="off"
<pride-badge shadow="off"></pride-badge>
<pride-badge trail="off"></pride-badge>
<pride-badge touch-trail="off"></pride-badge>
<pride-badge effects="off"></pride-badge>
